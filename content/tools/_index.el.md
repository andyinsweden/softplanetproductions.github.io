Καλωσόρισες. **Εργαστήρι Μουσικής Ελαιοπλανήτη** — πρακτικά εργαλεία που βασίζονται στο πρόγραμμα περιήγησης για να σας βοηθήσουν να κάνετε τη μουσική πιο συχνά.

## Ξεκινήστε με πέντε λεπτά αυτοσχεδιασμού

### [Καθημερινή Πρόκληση Αυτοσχεδιασμού Πιάνου](/el/tools/daily-piano-improvisation/)

Δείτε μια εύκολη στην παρακολούθηση εξέλιξη συγχορδίας σε ένα διαφορετικό κλειδί, ακούστε μια απλή συνοδεία πρακτική, ρυθμίστε το ρυθμό και σημειώστε τη συνεδρία σας ολοκληρωμένη. Το ιστορικό πρακτικής σας παραμένει στο δικό σας browser.

Αυτό είναι ένα καλό μέρος για να ξεκινήσετε αν μαθαίνετε να αυτοσχεδιάσετε, μπορείτε ήδη να παίξετε γραπτή μουσική, αλλά θέλετε να δημιουργήσετε τη δική σας, ή απλά θέλετε ένα σύντομο δημιουργικό ζέσταμα πριν από μια μεγαλύτερη συνεδρία εξάσκησης.

**[Ανοίξτε τη σημερινή δωρεάν πρόκληση για πιάνο](/el/tools/daily-piano-improvisation/)**

### [Εύρεση χορδής πιάνου](/el/tools/chord-finder/)

Παίξτε μια συγχορδία στο διαδραστικό πληκτρολόγιο για να την αναγνωρίσετε, ή εισάγετε ένα όνομα συγχορδίας για να δείτε και να ακούσετε τις σημειώσεις του. Δοκιμάστε διαφορετικές αντιστροφές, σημειώσεις τύπου, ή συνδέστε ένα πληκτρολόγιο MIDI σε ένα υποστηριζόμενο πρόγραμμα περιήγησης.

**[Ανοίξτε τον ελεύθερο ανιχνευτή χορδών πιάνου](/el/tools/chord-finder/)**

Θες να πάμε βαθύτερα; [Το δομημένο μάθημα αυτοσχεδιασμού πιάνου του Τζον Μοντγκόμερι](/el/courses/piano-improvisation/) για γενικές επιδείξεις, κινούμενες παρτιτούρες και ηχογραφημένες σκηνές υποστήριξης.

*Περισσότερα διαδραστικά μουσικά εργαλεία βρίσκονται σε εξέλιξη.*
