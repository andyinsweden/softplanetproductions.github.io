## 这是什么和弦?

选择 **识别和弦**,然后敲打钢琴键或键盘,例如 **C E G**. 再次按下突出显示的密钥以删除它 。 对于特定的发票,请输入八进制的注释,例如: **E3 G3 C4**,或者MIDI 注释编号,例如 **60 64 67**.

当输入没有八进制的音符时,查找者会按上升顺序排列,如输入时。 如果包含八进制或输入MIDI数字,无论输入的顺序如何,最低投注都会决定贝斯.

| 从最低到最高的注解 | 和弦符号 | 你正在玩的游戏 |
| --- | --- | --- |
| C–E–G | C | C 主要为根位置 |
| E–G–C | C/E | C 重置第一反转 |
| C–E♭–G–B♭ | Cm7 | C 第七小类 |
| G–B–D–F | G7 | 第七大类 |

发现者识别57种和弦,从主要的和小的三体到悬浮的,加注的和弦和改变的和弦. 它显示与相同音符相符的替代名称. 举例来说, **C–E–G–A** 可能是这样 **C6** 或 时 间 **Am7/C**。键和周围的和弦可以帮助您选择正确的名称。

## 看钢琴弦乐和反演

选择 **查找密钥**,然后输入和弦符号,例如: **Fmaj7**, **B♭m9** 或 时 间 **C/E**。突出显示的钢琴键显示发音。使用 **播放和弦** 一起听笔记,或者 **按顺序播放笔记** 以单独听到他们的声音。

斜线后面的音符指定了低音 **C/E**中,和弦是C大调,E小调是最低调。 **反转** 菜单,以查看同样的和弦如何与低音中不同的和弦吻合。

## 使用计算机键盘或 USB MIDI 钢琴

下级 **识别和弦**打开 **计算机键盘和 MIDI** 打开 **计算机密钥** 键盘。要使用 USB MIDI 键盘,请将其连接,选择 **连接 MIDI** 在支持Web MIDI并一起播放注释的浏览器中。 在电话或平板电脑上,在屏幕上敲琴或打音符.

## 切换你找到的和弦

试试看 **C–G–Am–F** 输入 [初学者的钢琴弦奏动向]({{< relref "tutorials/piano-chord-progressions-for-beginners" >}}). 向上查找每个和弦,并使用反转菜单来寻找彼此相近的形状. 然后练习 改变和弦与 [每日钢琴即兴练习]({{< relref "tools/daily-piano-improvisation" >}}).
