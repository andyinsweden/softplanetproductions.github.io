再生不足のサウンドから、awkwardスコアの間隔とPDFエクスポートの問題まで、50の一般的なSebelius問題に実用的なソリューションを見つけます。

これらの指示はデスクトップのシベリウスのために意図されています。 メニュー名と利用可能な機能は、Sebelius First、Artist、Ultimateなどのバージョンとエディションによって異なります。 コマンドが欠落している場合、その名前を Sibelius で検索するか、お使いのバージョンに提供されたリファレンスガイドを参照してください。

メジャーな変更を行う前に、スコアの別のコピーを保存します。

## サウンドとプレイバック {#sound-and-playback}

### 1. なぜシベリウスに音はありませんか?

再生ラインが動くが、何も聞かないと、音声出力、再生設定、ミキサーをチェックします。

**ソリューション**

1. スピーカーやヘッドフォンが別のアプリケーションで動作していることを確認してください。
2. **プレイ (Play)**タブから**再生装置 (Playback Devices)**を開きます。
3. **可聴周波エンジンの選択 (Audio Engine Options)**を開き、意図したオーディオインターフェイスを選択します。
4. インストールされた音源を使用する再生設定を選択します。
5. **ミキサー (Mixer)**を開き、ミュートされたチャンネル、ソロ楽器またはローマスターの音量をチェックします。

Sibeliusを起動した後にオーディオインターフェイスを接続したら、プログラムをインターフェイスに接続して再起動します。

**関連項目:** 問題2、5と6を参照してください。

### 2. なぜ、間違ったスピーカーやヘッドフォンを通じてシベリウスが再生するのですか?

Sibeliusは、オペレーティングシステムのデフォルトデバイスから異なる出力を使用できます。

**ソリューション**

1. 必要なデバイス上で接続して切り替えます。
2. **可聴周波エンジンの選択 (Audio Engine Options)** を開きます。
3. 適切なインターフェイスを選択します。
4. インターフェイスに複数の出力がある場合、出力ルーティングを確認してください。
5. 再生を再起動します。

デバイスが見つからない場合、シベリウスを閉じて、オペレーティングシステムがプログラムを再オープンする前にそれを認識していることを確認します。

Bluetooth デバイスは、追加の遅延が発生する可能性があります。

### 3. なぜ再生バッククラックル, クリックまたはブレイクアップ?

あまり小さいオーディオバッファは、特に要求の厳しいサウンドライブラリで中断された再生を引き起こす可能性があります。

**ソリューション**

1. **可聴周波エンジンの選択 (Audio Engine Options)** を開きます。
2. 1つの利用可能なステップでバッファサイズを増加させます。
3. 要求の厳しい通路を再生し、再び耳を傾けます。
4. 不要なアプリケーションを閉じます。
5. インターフェースドライバーがオペレーティングシステムをサポートしていることを確認してください。

再生が安定するまで繰り返します。 音が歪んだままの場合、ミキサーレベルもチェックします:クリッピングとバッファの問題は異なる修正が必要です。

### 4. なぜ私は私のMIDIキーボードを再生するとき、遅延はありますか?

キーを押すと音を聴く間の時間はレイテンシーと呼ばれます。

**ソリューション**

1. **可聴周波エンジンの選択 (Audio Engine Options)** を開きます。
2. バッファサイズを徐々に減らします。
3. 各変更後にキーボードをテストします。
4. クリックすると、バッファが若干増加します。

Windows では、利用できるときインターフェイス製造業者の ASIO の運転者を使用します。 macOSでは、コアオーディオデバイスを適切に使用しています。

レスポンシブなキーボード監視が必要な場合は、Bluetoothヘッドフォンを避けてください。

### 5. なぜ1つの器械は無声ですか。

単一のサイレントスタッフは通常、ミキサーの設定、サウンドアサインまたは再生プロパティにポイントされます。

**ソリューション**

1. **ミキサー (Mixer)** を開きます。
2. 楽器がミュートされていないことを確認してください。
3. 別の楽器がソロされているかどうかを確認してください。
4. スタッフに適切な音が割り当てられていることを確認してください。
5. 影響を受けるノートを選択し、利用可能な**インスペクター (Inspector)**の**パスで再生 (Play on pass)**設定を確認してください。

また、サイレント通過前に意図しない機器の変更を探します。

### 6. なぜシベリウスがミッシングや未使用の音を鳴らすのですか?

記法アプリケーションと音ライブラリは、別々のインストールを必要とする場合があります。

**ソリューション**

1. 再生構成が期待するサウンドライブラリをチェックします。
2. ライブラリがインストールされていることを確認します。
3. 必要に応じて、Avidアカウントから適切なインストーラを入手してください。
4. ライブラリを移動したら、その場所を更新するためのサポート手順に従ってください。
5. Sibelius を再起動し、マッチする再生設定を選択します。

本アプリケーションを再インストールすると、大きな音ライブラリが再インストールされると仮定しないでください。

### 7. なぜ間違った音を再生する楽器は?

スタッフのインストゥルメント定義やミキサーの割り当ては、期待する音と一致しないかもしれません。

**ソリューション**

1. スタッフにどの機器が割り当てられているかを確認します。
2. スコアの楽器の変更を探します。
3. 選択した再生設定を確認してください。
4. **ミキサー (Mixer)**でスタッフの音割り当てを確認します。

楽器自体を変更する必要がある場合は、適切な**機器変更 (Instrument Change)**を作成します。 スタッフだけの名前を変更しても、音楽の定義や再生音は変わりません。

### 8. なぜダイナミックスがPlaybackに影響しないのですか?

不適切なテキストスタイルで入力されたダイナミックスや、間違った位置に取り付けられた場合、意図した結果が生成されない場合があります。

**ソリューション**

1. ダイナミックが始まるべきノートを選択します。
2. **表現テキスト (Expression Text)** を作成します。
3. テキストスタイルの単語メニューを使用して動的に入力します。
4. 意図したスタッフに取り付けて、打ち負かしていることを確認してください。
5. マーキングの前に少しから通路を再生します。

動的にまだ効果が少ない場合は、別の再生音をテストします。 サウンドライブラリは、彼らがどのように変化するかで異なります。

### 9. なぜシベリウスは私のテンポマークを無視するのですか?

「Allegro」という見出しは、必ずしも再生のテンポ命令として機能しない。

**ソリューション**

1. **テンポテキスト (Tempo Text)**または適切な**メトロノームマーク (Metronome Mark)**テキストスタイルでマークを作成します。
2. 正確な速度のために、認識されたビートユニットとテンポ値が含まれます。
3. 添付ファイルの位置を確認してください。
4. 再生が意図的にテンポを変えている場合、**パフォーマンス (Performance)**の設定を確認します。

スコア全体が一貫して速いか、または遅いと鳴らせば、再生のテンポ制御を同様に点検して下さい。

### 10. なぜ、繰り返しや最初と第二の終了が誤って再生するのですか?

プレイバックは、ラインやテキストラベルの視覚的な外観だけでなく、繰り返し構造に依存します。

**ソリューション**

1. 適切な繰り返しのバラインを使用して下さい。
2. 適切な第一線と第2線タイプを使用して終端ラインを作成します。
3. 各終了が目的のバーで始まり、終了することを確認します。
4. 繰り返し再生設定と手動リピートシーケンスを見直します。
5. 繰り返しセクションの前に再生をテストします。

「D.S」や「D.C」のように見えるような通常のテキストではなく、認識された繰り返しの指示を使用してください。

## MIDIとノート入力 {#midi-and-note-input}

### 11. SibeliusがMIDIキーボードを認識しない理由は?

デバイスは、オペレーティングシステムに利用できなくなったり、シベリウスで無効にすることができます。

**ソリューション**

1. Sibelius を開く前にキーボードを接続します。
2. **設定 → 入力デバイス (Preferences → Input Devices)** を開きます。
3. 正しいデバイスを有効にします。
4. キーを再生し、入力インジケータを確認します。
5. デバイスが不足している場合は、別のUSBポートまたはケーブルをテストします。

ハブが関与している場合は、コンピュータに直接接続してみてください。 キーボードが1つ必要とすれば製造業者の運転者を取付けて下さい。

### 12. なぜ私は私のキーボードをヒーアーすることができますが、ノートは現れません?

シベリウスが現在記法に入るという意味ではなく、聴覚を聴く。 キーボードは、独自に独自のサウンドを制作することも可能です。

**ソリューション**

1. 入力が始まる場所または位置を選択します。
2. ノート入力モードを入力します。
3. **キーパッド (Keypad)**の期間を選択します。
4. メモを再生します。

ライブ録画の場合は、ステップタイム入力ではなく**フレックスタイム (Flexi-time)**を使用します。 ノートがまだ現れない場合は、キーボードが**入力デバイス (Input Devices)**で有効になっていることを確認してください。

### 13. なぜ間違ったオクターブにノートが入ったのですか?

オクターブシフトは、キーボードの設定や機器の表記規則に由来することができます。

**ソリューション**

1. キーボードのオクターブとトランスポーズコントロールをチェックします。
2. 通常のピアノスタッフの入力テスト。
3. オリジナルのスタッフに割り当てられた機器を確認してください。
4. コンサート・ピッチとトランスポーズ・スコアのビューを比較します。

ギターやピッコロなど、従来は書かれたノートから離れてオクターブを鳴らす楽器。 異なる間隔で楽器を転写する他。

### 14. MIDIノートが2回入力されるのはなぜですか?

同一のパフォーマンスがSibeliusを1つのMIDIルート以上で到達したときに重複入力が発生することがあります。

**ソリューション**

1. **入力デバイス (Input Devices)** を開きます。
2. 意図したキーボード入力だけを一時的に有効化します。
3. 不要なMIDI接続を切断します。
4. MIDIルーティングアプリケーションまたはインターフェイス設定を確認してください。
5. ひとつのメモをもう一度テストします。

音が2倍に聞こえるが、ノートだけ現れた場合は、音声監視とキーボードの**ローカルコントロール (Local Control)**設定を代わりに調べてください。

### 15. なぜフレックスタイム録画はメッシーリズムを生成するのですか?

ライブインプットは、あなたが意図した音楽のためにあまりにも正確に解釈されるかもしれません, 不要なショートノートを作成, 残りや小道具.

**ソリューション**

1. **フレックスタイムオプション (Flexi-time Options)** を開きます。
2. パスに合わせて最小限のノート値を設定します。
3. 必要ない場合は、タプレットを制限します。
4. 透き通ったテンポをクリアクリックで記録します。
5. 短い通過を記録し、続行する前にそれを見直します。

複雑な音楽では、ステージタイム入力はライブ録画よりも少ない補正を要求できます。

### 16. 別々のノートではなく、コードを入力するにはどうすればよいですか?

ノートは、ステップタイム入力で別の後に1つを通常占有成功的なリズム位置を占めています。

**ソリューション**

MIDI入力の場合は、必要な期間を選択した後、コードのメモを一緒に再生します。

コンピュータキーボード入力のため:

1. 初めてのメモを入力してください。
2. 選択する
3. 間隔コマンドを使用して、上記のメモを追加または下に追加します。

結果のノートが1つの茎と期間を共有していることを確認してください。

### 17. 数字キーパッドなしでメモを入力するにはどうすればよいですか?

ノートパソコンに別々のナンバーパッドがない場合でも、Sibeliusの画面上の**キーパッド (Keypad)**を使用できます。

**ソリューション**

1. パネル制御から**キーパッド (Keypad)**を表示します。
2. 必要な期間またはアーティキュレーションをクリックします。
3. コンピュータのキーボードまたはMIDIキーボードでピッチを入力します。
4. **リファレンス (Preferences)**で利用可能なキーボードショートカットセットのレビュー。

また、頻繁に通知を入力すると、ショートカットをカスタマイズしたりUSBの数値キーパッドを接続することもできます。

### 18. なぜ新しいノートは、既存の音楽を置き換えるのですか?

入力は選択したリズム位置で音楽を編集します。それは自動的にすべての新しい考えのための余分棒を作成しません。

**ソリューション**

1. 不要な編集をしないようにします。
2. 新しい通路に入る前に必要なバーを追加します。
3. 新規バーに最初の休憩を選択します。
4. メモ入力を開始します。

同じスタッフに追加の独立したリズムが必要な場合は、既存のボイスを交換するのではなく別の音声を使用します。

## ノテーション、声とリズム {#notation-voices-and-rhythm}

### 19. Entireバーの追加または削除方法は?

メモを削除し、バーを削除しても異なる操作です。

**ソリューション**

バーを追加するには、**ホーム →バー→追加 (Home → Bars → Add)** を使用して、適切なオプションを選択します。

棒を削除するため:

1. すべてのステージにバーの**システム選定**を作る。
2. 選択が削除したいバーを正確に含んでいることを確認してください。
3. 選択を削除します。

通常の通路の選択は、バーを所定の位置に残しながら音楽コンテンツをクリアすることができます。

### 20. 予想外に動くノートなしで拍子を変更するにはどうすればよいですか?

メーターを変更することで、既存の音楽を新しいバーに再編させることができる。

**ソリューション**

1. スコアのコピーを保存します。
2. 変更が始まる場所を選択します。
3. **拍子ー (Time Signature)** コントロールを開きます。
4. 既存のバーを書き換えるオプションを確認します。
5. 変更を適用し、影響を受ける通路を検査します。

既存のバー構造を保持するリライトを無効にしますが、表示されたメーターと一致しないバーを残すことがあります。 そのオプションを意図的に使用してください。

### 21. ピックアップバーまたはアンクルーシスを作成するにはどうすればよいですか?

ピックアップは、4/4の部分の最初のフルバーの前に、1ビートなどの短縮されたオープンバーです。

**ソリューション**

開口部時刻のシグネチャを作成する際は、**ピックアップ/アップビート**オプションを使用し、その期間を指定します。

既存のスコアでは、バー・クリエーション・コントロールを使用して必要な長さの **不規則なバー** を作成し、開口部を慎重に転送します。

部分が補完的な短縮エンディングを必要とする場合は、バー番号と最終バーを確認してください。

### 22. 1人のスタッフに2つの独立したリズムを置く方法は?

同時ミュージカルラインの音声を別々に使おう。

**ソリューション**

1. **音声 1**で最初の行を入力してください。
2. 2行目線の開始位置を選択します。
3. **キーパッド (Keypad)**で**ボイス2**を選択します。
4. ノートを入力し、独立して休息します。

ボイス1と2は、通常、反対の茎指示を提供します。 記法が必要なときにのみ、追加の音声を使用します。

メモが異なるリズムを必要とするときにコードを使用しないでください。

### 23. 私のスコアで余分な残りが現れるのはなぜですか?

各アクティブボイスには独自のリズム構造が必要ですので、追加の音声は追加のレストを紹介します。

**ソリューション**

1. 予期しない休息を選択し、その声を識別します。
2. バーで必要なメモが含まれているかどうかを確認してください。
3. 誤って作成した音声を適切に削除します。
4. 演奏会が音楽的に有効な場合のみ、休息を隠します。

不完全なリズムを隠すために単に休息を隠すことを避けて下さい。 最初に、各ボイスアカウントが意図したバーの持続時間を確認してください。

### 24. トリプルや他のタプレットを作成するにはどうすればよいですか?

タプレットは、通常のグループ化とは異なるリズムスパンを分割します。

**ソリューション**

1. 意図したベース期間でノートまたは残りを選択します。
2. **ノート入力 →の小道具 (Note Input → Tuplets)** を使う。
3. 必要なタプルを選択するか、カスタム比を入力します。
4. 残りのメモを入力してください。

普通の8本三重の場合は、8本目で始まる。 たとえタプルトが間違ったスパンを占有する場合、それをやり直し、開始時間と比率を確認します。

### 25. 私のメモが間違っているのはなぜですか?

ビームグループ化はメートル、そのグループ設定および手動ビーム変更に依存します。

**ソリューション**

1. シグネチャのビートグループ化時間を確認してください。
2. 影響を受けるメモを選択します。
3. **キーパッド (Keypad)** ビーム制御を使用して、必要に応じてビームを開始、継続、またはブレイクします。
4. 再発の問題については、手動ですべてのビームを修正するのではなく、グループ設定を調整します。

たとえば、6/8は通常3つの2つのグループに8つのメモをグループ化しますが、他のメートルは異なるパターンを必要とする場合があります。

### 26. 2つのStavesを渡るビームノートはどうなりますか?

クロススタッフの記法は、手間で共有されたピアノ通路に役立ちます。

**ソリューション**

1. 発祥のスタッフに通路を入力してください。
2. 他のスタッフに表示されるメモを選択します。
3. **クロススタッフノート (Cross-staff Notes)** コマンドを使用して、上記または下にある表示を移動します。
4. 茎、梁、スタッフの間隔を見直します。

クロススタッフの動きは、元の声にメモの関係を保ちます。 通常のカットとペーストは、他のスタッフに音楽を移動させ、同じ表記を生成しない可能性があります。

### 27. なぜ私のタイはスラリーのように美食していますか?

テスとスラは異なる音楽の意味を持っています。

**ソリューション**

**ティエ** を使用して、同じピッチの連続したメモを 1 つの持続期間に結合します。 **キーパッド (Keypad)**タイ制御で適用して下さい。

**スラリー** を使用して、ノートを渡るフレーズまたはアーティキュレーションを示します。 **スラリー (Slur)** コマンドを使って作成します。

ネクタイが正しく接続しない場合は、次のノートのピッチ、誤って、音声とリズムの位置を確認してください。

### 28. なぜ事故が起きているのか?

シベリウスは、キーシグネチャから偶然の表示を決定します。, バーの以前のメモと表記の設定.

**ソリューション**

1. 鍵の署名を確認してください。
2. 同じバーのピッチの以前の発生を確認してください。
3. ノートを選択し、**キーパッド (Keypad)**を使用して事故を検査します。
4. 読みやすさを改善する注意的な事故を追加します。

実際のピッチは、シンボルを強制的に表示させるだけを変更しないでください。 アクシデンシャルディスプレイと音楽のピッチは両方とも正しい必要があります。

### 29. ノートのエンハーモニックスピーリングを変更するにはどうすればよいですか?

フラットな綴りが調和に合えば、ピッチはシャープに入るかもしれません。

**ソリューション**

1. ノートまたはパスを選択します。
2. **リスペル (Respell)**コマンドを使用します。
3. chord と key に対するスペルをチェックします。

例えば、F-sharp というノートは、特定の調和的なコンテキストで G-flat として記述する必要があるかもしれません。

音の響きを記憶する。 変化のピッチをトランスポーズし、異なる問題を解決します。

### 30. なぜ、シベリウスのノートレッド?

レッド・ノートヘッドは、一般的には、ピッチが楽器の定義範囲外にあることを示しています。

**ソリューション**

1. スタッフに割り当てられた機器を確認してください。
2. 筆記と音のピッチを見直します。
3. 計測範囲の表示設定を確認してください。
4. 意図したプレーヤーに適した通路かどうかを決めます。

範囲警告は、自動的に通知が間違っているという意味ではありません。 しかし、色を隠すと、非現実的なノートが再生できない。

## スコアのレイアウトおよび間隔 {#score-layout-and-spacing}

### 31. 1つのシステムで、もっと多くのバーやフェーテルバーに合う方法は?

シベリウスは、システムの長さを自動的に計算しますが、重要な休憩を制御できます。

**ソリューション**

1. 1つのシステムを共有するバーを選択します。
2. **レイアウト → フォーマット → システムに作ります (Layout → Format → Make Into System)** を使う。
3. 混雑したメモとテキストの結果を調べます。

また、バーラインを選択し、**システムブレイク (System Break)**を追加します。

多くのシステムが混み合っている場合、スタッフのサイズ、ページマージンとメモの間隔を見直して、各行に複数のバーを強制するのではなく。

### 32. なぜシベリウスが私のスコアを退却しませんか?

既存の書式ロックとブレイクは自動レイアウト変更を防ぐことができます。

**ソリューション**

1. レイアウトのマークを表示します。
2. システムブレイク、ページブレイク、ロックされたシステムを探します。
3. 影響を受ける通路を選択します。
4. **フォーマットのロック解除 (Unlock Format)**は、適宜ご使用ください。
5. 必要な休憩だけを再適用して下さい。

スコアが既に準備されたページが変わったり、出版のレイアウトがあったらコピーを最初に保存して下さい。

### 33. なぜ大きなガップは、Stavesの間にありますか?

手動の動き、衝突回避または垂直正当化による大きなギャップが生じる場合があります。

**ソリューション**

1. 影響を受けるシステムを選択します。
2. **スタッフのスライディングを最適化 (Optimize Staff Spacing)** を使う。
3. 歌詞、ダイナミクス、ライン、テキストを占有するギャップを探します。
4. ページ全体にステージが広がる場合は、縦の正当設定を確認してください。

以前のマニュアルの変更が原因である場合は、再度最適化する前に、適切なスタッフスパッチリセットコマンドを使用します。

### 34. なぜダイナミックス、歌詞またはテキストコライドをしますか?

自動衝突回避は、混雑したレイアウトを解決できないか、無効にすることができます。

**ソリューション**

1. 影響を受けたオブジェクトに対して **磁気レイアウト (Magnetic Layout)** が有効になっていることを確認します。
2. 不要な手動位置をリセットします。
3. スタッフの間隔を最適化します。
4. 必要に応じて、システムに水平空間を与えます。
5. 自動レイアウトを点検した後にのみ小さな手動調整を行います。

あまりにも多くの音楽を含むシステムは、衝突の設定に関係なく、バーが少ない場合があります。

### 35. どのように私は不均等な横のノートの間隔を復元しますか?

メモをドラッグしたり、間隔を繰り返し変更したりすると、矛盾するような通路を残すことができます。

**ソリューション**

1. 影響を受ける通路を選択します。
2. **出現 →はノート→の調整のノートの間隔を調節します (Appearance → Reset Notes → Reset Note Spacing)** を選択します。
3. 歌詞、コードのシンボル、偶発的な周りの間隔を調べます。
4. 通路が混雑したままであれば、システムが壊れるのを調節します。

特定のオブジェクトがまだそのノートから遠くに座っている場合は、その個々の位置も確認します。

### 36. どのように私は空の彫像を隠すのですか?

未使用のストールを隠すと、大きなアンサンブルスコアが読みやすくなります。

**ソリューション**

1. 関連するシステムまたは通路を選択します。
2. **レイアウト→の隠れるStaves →は空のStavesを隠します (Layout → Hiding Staves → Hide Empty Staves)** を選択します。
3. 必要なすべての機器が表示される状態を確認してください。

メモや関連したオブジェクトを含むスタッフは、空のように修飾されない場合があります。 何も削除する前にそれを調べます。

スタッフが再び表示されるようにする必要がある場合は、**空のステーブを表示する (Show Empty Staves)**を使用してください。

### 37. 楽器の注文を変更するにはどうすればよいですか?

機器ラベルの変更は、スタッフを移動させません。

**ソリューション**

1. **ホーム → 機器 → 追加または削除 (Home → Instruments → Add or Remove)** を開きます。
2. スコアの楽器リストで機器を選択します。
3. 上下に移動します。
4. 変更内容の確認
5. ブラケット、括弧およびバリンのグループ化を見直して下さい。

アンサンブルにふさわしい注文を選択し、音楽家が自分の部品を素早く見つけるのを助けます。

### 38. なぜ器械名が間違っているか、または逃しているのか?

機器名は、最初のシステムと後続のシステム間で異なる場合があります。

**ソリューション**

1. 楽器のフルネームとショート名を確認してください。
2. 表示される名前またはその機器の設定を適切に編集します。
3. スコアのインストゥルメンタル名表示設定を確認します。
4. 楽器が別のラベルを導入するかどうかを確認してください。

リーダーが識別を必要とするフルネームと、その後のシステム上で明確な省略語を使用する。

### 39. なぜ期待されていない空白のページはありますか?

空白のページは、特別なページブレイク、タイトルページの設定、またはインポートされたフォーマットからなる場合があります。

**ソリューション**

1. レイアウトのマークを表示します。
2. 前ページの末尾を点検します。
3. ブランクページを差し込む **特設ページブレイク (Special Page Break)** をチェックします。
4. 責任あるブレイクを取消し、または調節して下さい。
5. レイアウト変更後の次のページを確認します。

フォーマットによって作成されたページを削除するために音楽を削除しないでください。

### 40. なぜバー番号が間違って起動または再起動しますか?

ピックアップ、移動境界または偶然のバー番号の変更は、番号付けに影響を与えることができます。

**ソリューション**

1. 番号が間違っている箇所を調べます。
2. **棒数変更 (Bar Number Change)**のチェック
3. 変更を修正または削除します。
4. bar-number の表示設定を確認します。
5. スコアと部品の両方で番号を確認する。

開口部のピックアップが無数であるか、またはカウントされるかを決定し、その後、一貫して条約を適用します。

## 部品、印刷および輸出 {#parts-printing-and-exporting}

### 41. 個々のインストゥルメンタルパーツを作成するにはどうすればよいですか?

**動的部品 (Dynamic Parts)**は、楽譜と楽器のパーツを音楽コンテンツをシェアできるようにします。

**ソリューション**

1. **パーツ名 (Parts)** コントロールを開きます。
2. 既に存在する部品を確認してください。
3. 必須部分を開きます。
4. サポートされている場所で、新しい部分を作成し、含まれているべきステーブを選択します。
5. プレーヤーのレイアウトを調整します。

リンクされたスコアとパートのワークフローで音楽編集を続けます。ただし、別のファイルを非必要に維持するのではなくです。

### 42. なぜ私のインストゥルメンタルパートはスコアから異なるレイアウトを持っていますか?

部品はページ・ターン、スタッフのサイズおよびシステム壊れ目を含む独立したレイアウトの条件を備えています。

**ソリューション**

1. 影響を受ける部分を開きます。
2. **ドキュメントのセットアップ (Document Setup)** をチェックしてください。
3. 自動ブレイクと手動ブレイクを見直します。
4. パーツのレイアウトを直接調整します。

レイアウトの違いは、通常想定されます。 メモやリズムが間違っている場合は、正しいリンクされた部分を閲覧しているか、その内容が隠されていないことを確認してください。

### 43. なぜマルチレストが私の部品に欠けているか、分割されているのですか?

マルチレストは、音楽の指示やオブジェクトによって表示され続ける必要があります。

**ソリューション**

1. 部分にmultirestsが有効になっていることを確認します。
2. マルチレストが壊れるバーを調べます。
3. リハーサルマーク、テキスト、バランス、キー変更、拍子をチェックします。
4. 誤った物は、不必要な確認後にのみ削除します。

プレイヤーがその時点での指示を見る必要があるため、いくつかのブレイクは正しいです。

### 44. より良いページを作成する方法は、部品で回りますか?

プレイヤーは、次のエントリを欠落させずにページをオンにするのに十分な時間が必要です。

**ソリューション**

1. 個々の部分を開いたら。
2. ページのターンに適したレストを見つけます。
3. Insertページは、実用的な位置で破棄します。
4. 利用可能な自動ページターンオプションを確認します。
5. 最終ページ数とシステム間隔を確認します。

ターンを強制するために、非常に混雑したページを作成しないでください。 プレーヤーの視点からレイアウトをテストします。

### 45. 私のPDFが間違ったサイズやマージンを持っているのはなぜ?

スコアのページのセットアップと印刷やエクスポートの設定は同意できません。

**ソリューション**

1. **ドキュメントのセットアップ (Document Setup)**のページサイズとオリエンテーションを確認します。
2. 証拠金とスタッフのサイズを確認してください。
3. 意図したスコアや部分をエクスポートしていることを確認してください。
4. 内蔵PDFエクスポートを使用して、利用可能な場所。
5. PDF を開き、ページ寸法を確認します。

印刷時、用紙サイズとスケーリングを別途確認します。最終プリントスタッフのサイズを変更できます。

### 46. なぜ音楽のシンボルやフォントがPDFで間違っているのですか?

フォント、置換、フォント関連のエクスポートの問題の欠如は、表記の出現を変えることができます。

**ソリューション**

1. 画面上のスコアでPDFを比較します。
2. 必要な音楽とテキストフォントがインストールされていることを確認してください。
3. Sibeliusの組み込みPDFエクスポートを試してみましょう。
4. 別のPDFビューアで結果を開きます。
5. シンボルがSibelius内でも間違っている場合は、アプリケーションのフォントのインストールを調べます。

カスタムフォントのみが失敗した場合は、スコアのコピーで標準フォントをテストします。

### 47. オーディオファイルをエクスポートできないのはなぜですか?

オーディオエクスポートは、コンピュータ内の音をレンダリングできる再生構成が必要です。

**ソリューション**

1. 選択した再生設定を確認してください。
2. サポートされている仮想機器または内部再生音源を使用します。
3. 通常の再生が動作することを確認します。
4. 利用可能な**ファイル → エクスポート → オーディオ (File → Export → Audio)**を選択します。

再生が外部ハードウェアのシンセサイザーを使用している場合、その音はオーディオインターフェイスを介して録音する必要があるかもしれません。 MIDIをデバイスに送信すると、そのオーディオがキャプチャされません。

## 保存、回復および性能 {#saving-recovery-and-performance}

### 48. クラッシュ後にスコアを回復するにはどうすればよいですか?

回復は、中断前に保存されたシベリウスに依存します。

**ソリューション**

1. Sibelius を再オープンし、回復プロンプトを確認します。
2. 利用可能なオートセーブまたはバックアップファイルを調べます。
3. お使いのバージョンの保存設定やリファレンスガイドに表示されている場所を使用してください。
4. タイムスタンプと音楽コンテンツを比較します。
5. 新しい名前の下で最高の回復バージョンを保存します。

復元したファイルが必要な作業を含むことを確認するまで、元の上書きを避けてください。

### 49. なぜシベリウスは遅いですか、凍結するか、またはクラッシュしますか?

原因は、特定のスコア、再生ライブラリ、ドライバまたはソフトウェアコンポーネントを含む場合があります。

**ソリューション**

1. 作業を保存し、シベリウスを再起動します。
2. 小さな新しいスコアをテストします。
3. 問題のあるスコアで行動を比較します。
4. より簡単な再生設定をテストします。
5. 不要なMIDIとオーディオ機器を切断します。
6. 互換性のあるシベリウスとドライバの更新を確認してください。

スコアが1つだけ失敗した場合、コピーで作業し、影響を受ける通路を狭くします。 すべてのスコアが失敗した場合は、バージョン、オペレーティングシステム、およびサポートのための正確なエラーメッセージを記録します。

### 50. なぜ誰かが自分のシベリウスファイルを開くことができないのですか?

受信者は、古いバージョン、制限されたエディション、またはファイルの不完全なコピーを持っている可能性があります。

**ソリューション**

1. Sibeliusバージョンとエディションを使用するかどうかを尋ねます。
2. サポートされている場合は、**ファイル → エクスポート → 前バージョン (File → Export → Previous Version)** を使用します。
3. エクスポートされたコピーを送って、元のコピーを保って下さい。
4. 転送されたファイルが完成していることを確認してください。
5. 別の表記アプリケーションを使用する場合は、MusicXML を検討してください。

古いバージョンのエクスポートとMusicXMLは、フォーマットやサポートされていない機能を変更できます。 編集可能なファイルを視覚的に参照してPDFを送信します。

## クイックトラブルシューティングチェックリスト {#quick-troubleshooting-checklist}

主な変更を行う前に:

1. スコアの別のコピーを保存します。
2. 問題が1つのスコアかすべてのスコアに影響を及ぼすかどうかを識別して下さい。
3. 選択したオーディオとMIDIデバイスを確認します。
4. 再生設定を確認してください。
5. 最近の表記やレイアウト変更を調べます。
6. 必要に応じてシベリウスを再起動します。
7. バージョンとオペレーティングシステムの互換性をチェックします。
8. 1つの設定を時間単位で変更し、結果をテストして下さい。
