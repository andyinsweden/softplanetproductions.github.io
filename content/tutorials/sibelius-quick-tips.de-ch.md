*By John Montgomery*

Sie haben die Melodie in Ihrem Kopf. Die Partitur ist offen. Dann unterbricht eine kleine Softwarefrage den Fluss: Wo ist die Instrumentenliste, warum ist die Wiedergabe leise, oder wie drückt man diese Balken auf eine Zeile?

Ein paar vertraute Befehle können Ihnen helfen, zurück zur Musik zu gelangen. Halten Sie diese kurze Anleitung für Ihre nächste arrangierende Sitzung in der Nähe und versuchen Sie eine neue Verknüpfung nach und nach.

Diese Tipps betreffen die **Desktop-Ausgaben von Sibelius**. Verfügbare Befehle hängen von Ihrer Edition und Version ab; angepasste Verknüpfungen können von den unten aufgeführten Standardeinstellungen abweichen.

## 1. Geben Sie Ihrer Partitur die richtigen Instrumente

Drücken Sie **I**, um **Startseite > Instrumente > Hinzufügen oder Entfernen** zu öffnen. Von hier aus können Sie ein Instrument hinzufügen, ein Personal entfernen, das Sie nicht mehr benötigen, oder die Reihenfolge ändern, in der die Instrumente erscheinen.

Es ist ein nützlicher erster Schritt, wenn eine Skizze in eine Anordnung verwandelt wird. Holen Sie sich das Line-up rechts, dann konzentrieren Sie sich auf das, was jeder Spieler sehen muss.

Das Hinzufügen oder Umbestellen von Notenblättern unterscheidet sich von dem Einfügen eines Instrumentenwechsels auf halbem Wege durch ein vorhandenes Teil. Suchen Sie für einen Spieler, der Instrumente verdoppelt, nach dem in Ihrer Ausgabe verfügbaren Befehl Instrumentenwechsel, anstatt einfach ein anderes Notensystem hinzuzufügen.

## 2. Machen Sie Drillinge fühlen sich einfach

Beginnen Sie mit der ersten Note der Gruppe, indem Sie den Notenwert verwenden, den jede Tripletnote haben soll. Geben Sie zum Beispiel einen Quaver ein oder wählen Sie einen Quaver, um einen Quaver Triplet zu beginnen.

Drücken Sie **Ctrl + 3** unter Windows oder **Command + 3** auf Mac, indem Sie die Nummernzeile auf der Haupttastatur verwenden.

Wenn das Ergebnis den falschen Betrag der Leiste belegt, überprüfen Sie zuerst den Wert der Anfangsnote. Die Verknüpfung erzeugt die Gruppe aus diesem Wert; sie entscheidet nicht, welche Art von Triplet Sie beabsichtigten.

## 3. Bringen Sie die Wiedergabe zurück in den Raum

Wenn Sibelius still ist, überprüfen Sie zunächst die einfachen Dinge: Ihr Computer .s Ausgabevolumen, die Kopfhörerverbindung und ob eine andere Anwendung Klang durch das beabsichtigte Gerät abspielen kann.

Als nächstes öffnen Sie **Wiedergabe > Setup > Wiedergabegeräte**, dann **Optionen für Audio-Engine (Audio Engine Options)** und wählen Sie die gewünschte Schnittstelle. Die Route kann in Ihrer Version etwas anders erscheinen; Avids illustrierte Anleitung ist unten verlinkt.

Wenn Sie Kopfhörer oder eine Schnittstelle nach dem Öffnen von Sibelius angeschlossen haben, speichern Sie Ihre Arbeit und versuchen Sie, die Anwendung mit dem bereits angeschlossenen Gerät neu zu starten. Dies ist ein nützlicher Fehlerbehebungsschritt, anstatt eine Regel, dass jedes Gerät immer einen Neustart benötigt.

Immer noch leise? Überprüfen Sie die Wiedergabekonfiguration und das Sound-Bibliotheks-Setup mit unserem detaillierteren [Sibelius Anleitung zur Fehlerbehebung](/de-ch/tutorials/sibelius-troubleshooting/).

## 4. Gestalten Sie die Seite ohne Ringen mit ihm

Eine ordentliche Seite sollte Musikern helfen, bequem zu lesen. Vier Balken pro Linie können gut für eine einfache Übung funktionieren, aber ein dichter Durchgang kann mehr Platz benötigen.

Um eine bestimmte Passage auf einem System zu platzieren, wählen Sie die Balken und verwenden Sie **Layout > Format > In das System einbauen**. Seine Standard-Verknüpfung ist **Shift + Alt + M** unter Windows oder **Shift + Option + M** auf Mac.

Verwenden Sie diesen Befehl selektiv: es sperrt den Durchgang in ein System. Wenn das Ergebnis überfüllt aussieht, rückgängig machen und überdenken Sie den Abstand, die Personalgrösse oder die Anzahl der Balken. Avid warnt davor, routinemässig Durchgänge in Systeme zu zwingen, weil es die Formatierung anderswo beeinflussen kann.

Für wiederholte Layoutmuster, erkunden Sie **Layout > Automatische Unterbrechungen**, wo verfügbar. Vorschau auf das Ergebnis vor dem Drucken, und machen Lesbarkeit der entscheidende Faktor.

## 5. Überprüfen Sie die Lizenz vor der Änderung der Partitur

Wenn Sibelius mit weniger Funktionen als erwartet öffnet, überprüfen Sie das in **Verstärkte Verknüpfung (Avid Link)** gezeigte Produkt und die Lizenz. Achten Sie darauf, dass Sie in das Avid-Konto eingetragen sind, das die Berechtigung besitzt und folgen Sie den Aktivierungsanweisungen für Ihre Lizenzierungsmethode.

Der Umzug auf einen anderen Computer erfordert möglicherweise zuerst die Deaktivierung der alten Installation. Folgen Sie den Anweisungen von Avid für Ihre bestimmte Lizenz; Schul- und Netzwerkinstallationen benötigen möglicherweise Hilfe von einem Administrator.

Ein fehlender Befehl kann auch ein Editionsunterschied sein. Prüfen Sie, was Ihre Lizenz enthält, bevor Sie annehmen, dass die Partitur oder Installation defekt ist.

## Eine kleine Shortcut-Sammlung, die es wert ist zu lernen

| Aufgabe | Fenster | Mac |
| --- | --- | --- |
| Instrumente hinzufügen oder entfernen | I | I |
| Erstellen Sie ein Triplet aus der ersten Note | Ctrl + 3 | Command + 3 |
| Einen ausgewählten Durchgang in ein System machen | Shift + Alt + M | Shift + Option + M |

Wählen Sie den Befehl, den Sie am häufigsten verwenden, und üben Sie ihn in einer Kopie einer Partitur. Ein paar Sekunden immer wieder gespeichert kann eine Sitzung fühlen sich viel glatter.

## Beenden Sie mit der Ansicht des Spielers

Bevor Sie Ihre Anordnung teilen, überprüfen Sie die einzelnen Teile sowie die Partitur. Schauen Sie sich Seitenwechsel, überfüllte Passagen und die Klarheit Ihrer Anweisungen an. Eine Partitur ist ein Gespräch mit den Leuten, die es spielen: Machen Sie ihren nächsten Schritt einfach zu sehen.

Für weitere Hilfe, besuchen Sie unsere [Sibelius Anleitung zur Fehlerbehebung](/de-ch/tutorials/sibelius-troubleshooting/). Schulen, die ihre Notation Setup planen, können auch unsere [Sibelius Site-Lizenzierung Service](/de-ch/services/sibelius-site-licenses/) erkunden.
