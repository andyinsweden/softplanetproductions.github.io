*By John Montgomery*

You have the tune in your head. The score is open. Then a small software question interrupts the flow: where is the instrument list, why is playback silent, or how do you squeeze those bars onto one line?

A few familiar commands can help you get back to the music. Keep this short guide nearby for your next arranging session, and try one new shortcut at a time.

These tips concern the **desktop editions of Sibelius**. Available commands depend on your edition and version; customised shortcuts may differ from the defaults below.

## 1. Give your score the right instruments

Press **I** to open **Home > Instruments > Add or Remove**. From here you can add an instrument, remove a staff you no longer need or change the order in which the instruments appear.

It is a useful early step when turning a sketch into an arrangement. Get the line-up right, then concentrate on what each player needs to see.

Adding or reordering staves is different from inserting an instrument change midway through an existing part. For a player doubling instruments, look for the instrument-change command available in your edition rather than simply adding another staff.

## 2. Make triplets feel straightforward

Start with the first note of the group, using the note value you want each triplet note to have. For example, enter or select a quaver to begin a quaver triplet.

Press **Ctrl + 3** on Windows or **Command + 3** on Mac, using the number row on the main keyboard. Then enter the remaining notes normally.

If the result occupies the wrong amount of the bar, check the starting note value first. The shortcut creates the group from that value; it does not decide which kind of triplet you intended.

## 3. Bring playback back into the room

If Sibelius is silent, first check the simple things: your computer’s output volume, the headphone connection and whether another application can play sound through the intended device.

Next open **Play > Setup > Playback Devices**, then **Audio Engine Options**, and choose the intended interface. The route may appear slightly differently in your version; Avid’s illustrated guide is linked below.

If you connected headphones or an interface after opening Sibelius, save your work and try restarting the application with the device already connected. This is a useful troubleshooting step, rather than a rule that every device always requires a restart.

Still silent? Check the playback configuration and sound-library setup using our more detailed [Sibelius troubleshooting guide](/tutorials/sibelius-troubleshooting/).

## 4. Shape the page without wrestling with it

A tidy page should help musicians read comfortably. Four bars per line can work well for a simple exercise, but a dense passage may need more space.

To place a particular passage on one system, select the bars and use **Layout > Format > Make Into System**. Its default shortcut is **Shift + Alt + M** on Windows or **Shift + Option + M** on Mac.

Use that command selectively: it locks the passage into one system. If the result looks crowded, undo it and reconsider the spacing, staff size or number of bars. Avid cautions against routinely forcing passages into systems because it can affect formatting elsewhere.

For repeated layout patterns, explore **Layout > Auto Breaks**, where available. Preview the result before printing, and make readability the deciding factor.

## 5. Check the licence before changing the score

If Sibelius opens with fewer features than expected, check the product and licence shown in **Avid Link**. Make sure you are signed into the Avid account that holds the entitlement and follow the activation instructions for your licensing method.

Moving to another computer may require deactivating the old installation first. Follow Avid’s instructions for your particular licence; school and network installations may need help from an administrator.

A missing command can also be an edition difference. Check what your licence includes before assuming that the score or installation is broken.

## A small shortcut collection worth learning

| Task | Windows | Mac |
| --- | --- | --- |
| Add or remove instruments | I | I |
| Create a triplet from its first note | Ctrl + 3 | Command + 3 |
| Make a selected passage into one system | Shift + Alt + M | Shift + Option + M |

Pick the command you use most often and practise it in a copy of a score. A few seconds saved repeatedly can make a session feel much smoother.

## Finish with the player's view

Before sharing your arrangement, check the individual parts as well as the full score. Look at page turns, crowded passages and the clarity of your instructions. A score is a conversation with the people playing it: make their next step easy to see.
