## 声音和播放 {#sound-and-playback}

### 1. 为什么西贝利乌斯没有声音?

如果回放行动了但听不到,请检查音频输出,回放配置和混音器.

**解决方案**

1. 确认您的扬声器或耳机在另一个应用程序中工作 。
2. 打开 **回放设备 (Playback Devices)** 从 **播放( L) (Play)** 选项卡。
3. 打开 **音频引擎选项 (Audio Engine Options)** 并选择预定的音频接口。
4. 选择使用已安装声音源的播放回放配置 。
5. 打开 **混音器 (Mixer)** 并检查变声道、独奏乐器或低主音量。

如果在启动Sibelius后连接到音频接口,则用连接到的接口重启程序.

**相关 :** 参见问题2,5和6.

### 2. 为什么西贝利乌斯要通过错误的演讲者或耳机播放?

西贝柳斯可以使用与操作系统默认设备不同的输出.

**解决方案**

1. 连接和切换所需的设备.
2. 打开 **音频引擎选项 (Audio Engine Options)**.
3. 选择适当的接口。
4. 检查您的界面是否有多个输出 。
5. 重新开始播放。

如果设备丢失,在重启程序前关闭Sibelius并证实操作系统识别它.

蓝牙设备可能引入额外的延迟.

### 3. 为什么回放 crackle, 点击或断开 ?

音效缓冲器太小,可导致播放中断,特别是要求高的音效库.

**解决方案**

1. 打开 **音频引擎选项 (Audio Engine Options)**.
2. 将缓冲大小增加一个可用的步骤。
3. 演奏一段严苛的段落,再听一遍.
4. 关闭不必要的应用程序 。
5. 检查接口驱动程序是否支持您的操作系统 。

重复到播放稳定为止。 如果声音仍然扭曲,也检查混音级别:剪辑和缓冲问题需要不同的修正.

### 4. 为什么我玩我的 MIDI 键盘时会有延迟 ?

按键和听觉声音之间的时间叫做"耐久".

**解决方案**

1. 打开 **音频引擎选项 (Audio Engine Options)**.
2. 逐渐减少缓冲大小.
3. 每次更改后测试键盘.
4. 如果点击出现,请略微增加缓冲。

在Windows上,在可用时使用接口制造商的ASIO驱动程序. 在macOS上,使用相应的核心音频设备.

在需要响应键盘监控时避免蓝牙耳机.

### 5. 为什么一个乐器是寂静的?

单一的无声工作人员通常指其混音器设置,声音分配或回放属性.

**解决方案**

1. 打开 **混音器 (Mixer)**.
2. 请检查date=中的日期值 (帮助) 乐器没有哑音.
3. 检查另一个乐器是否独奏 。
4. 确认工作人员配有合适的声音。
5. 选择受影响的便条并检查其 **玩过关 (Play on pass)** 设置 **检查员 (Inspector)**,如果有的话。

在静音之前,还要寻找一个意外的仪器变化.

### 6. 为什么Sibelius的声音失踪或无法获取?

标记应用程序及其声音库可能需要单独安装。

**解决方案**

1. 检查您重播配置所期望的哪个声音库 。
2. 确认库已安装 。
3. 必要时,从您的 Avid 账户中获取相应的安装器 。
4. 如果您移动了库, 请遵循支持的程序更新其位置 。
5. 重新启动Sibelius并选择匹配的回放配置.

不要假设重置主应用程序也会重新安装一个大型声音库 。

### 7. 为什么乐器演奏错误的声音?

工作人员的仪器定义或混音器任务可能与你期望的声音不符。

**解决方案**

1. 检查哪个仪器是分配给工作人员。
2. 查找乐器在分数中的变化.
3. 检查选中的播放配置 。
4. 审查工作人员在《公约》中的合理分配 **混音器 (Mixer)**.

如果你需要改变乐器本身, 创建一个适当的 **仪器更改 (Instrument Change)**仅重新命名工作人员并不能改变其音乐定义或回放声音。

### 8. 为什么Dynamics不能影响回放?

输入的不适当的文本样式或附在错误位置上的动态可能不会产生预期结果。

**解决方案**

1. 选择该动态起始位置的注释。
2. 创建 **表达式文本 (Expression Text)**.
3. 使用文本样式的单词菜单插入动态 。
4. 请检查date=中的日期值 (帮助)
5. 从标记前略放一段.

如果动态仍然没有什么效果,则测试另一个回放声音. 声音库在如何应对动态方面有所不同.

### 9. 为什么西贝利乌斯忽略了我的临时标记?

“Allegro”这个标题不一定作为回放节奏指示发挥作用。

**解决方案**

1. 创建标记为 **临时文本 (Tempo Text)** 或适当的 **都会标 (Metronome Mark)** 文本样式。
2. 对于精确的速度,包括一个公认的节拍单位和节奏值.
3. 检查它的附件位置 。
4. 审查《公约》执行情况 **业绩 (Performance)** 如果播放故意改变节奏,则设置。

如果整个分数的音速一直太快或太慢,也检查回放节奏控制.

### 10. 为什么重复或第一和第二结局玩的不正确?

回放取决于重复结构,而不仅仅是一行或文本标签的视觉外观.

**解决方案**

1. 使用适当的重复条线。
2. 使用相应的第一端和第二端行类型创建结束行。
3. 检查每个结尾在预定的栏杆上开始和结束.
4. 审查重复播放设置和任何手动重复序列 。
5. 测试重播之前的重播 。

使用经确认的重复指示,而不是普通文本,这些普通文本只看上去像“D.S.”或“D.C.”。

## MIDI 和 注输入 {#midi-and-note-input}

### 11. 为什么Sibelius不认得我的MIDI键盘?

该设备可能断开,无法进入操作系统,或者在西贝柳斯被禁用.

**解决方案**

1. 在打开西贝利乌斯前连接键盘.
2. 打开 **首选项 → 输入设备 (Preferences → Input Devices)**.
3. 启用正确的设备 。
4. 播放密钥并检查输入指标。
5. 如果设备丢失, 请测试另一个 USB 端口或电缆 。

如果涉及一个中枢,请尝试直接连接到计算机. 如果键盘需要安装制造商驱动程序 。

### 12. 为什么我能听到我的键盘,但没有笔记出现?

听到声音并不意味着西贝利乌斯正在进入标记。 键盘也可能独立地产生自己的声音.

**解决方案**

1. 选择其他输入开始的位置。
2. 输入注释输入模式。
3. 选择时间长度 **键盘 (Keypad)**.
4. 弹个便条.

用于现场录音,使用 **Flexi 时间 (Flexi-time)** 。确认键盘在 **输入设备 (Input Devices)** 如果笔记仍然不出现。

### 13. 为什么在错误的奥克塔夫输入笔记?

八进制的转变可源于键盘设置或文书的注解公约。

**解决方案**

1. 请检查date=中的日期值 (帮助) 键盘的八进制和转动控制器.
2. 测试一个普通的钢琴手的输入.
3. 请检查date=中的日期值 (帮助) 分配给原工作人员的仪器.
4. 比较协奏曲-pitch和转录-积分视图.

一些乐器,包括吉他和皮科洛,在传统声音上与他们的书面音符相距八进制. 其他转录仪器的转录间隔不同.

### 14. 为什么MIDI笔记是两次输入的?

当同一性能通过一个以上的MIDI路由到达西贝利乌斯时,可以发生重复输入.

**解决方案**

1. 打开 **输入设备 (Input Devices)**.
2. 暂时只允许预定的键盘输入.
3. 断开不必要的 MIDI 连接.
4. 请检查任何 MIDI 路由应用程序或接口设置 。
5. 再试一注.

如果你听到翻倍的声音,但只出现一个音符, 调查音频监控和键盘的 **当地控制 (Local Control)** 设置。

### 15. 为什么Flexi-time录音 产生乱七八糟的韵律?

现场输入可能会被解读得过于精确,以达到你想要的音乐,创造出不想要的短音,休息或小调.

**解决方案**

1. 打开 **Flexi 时间选项 (Flexi-time Options)**.
2. 设置最小的注值以适应段落.
3. 不需要的话,请限制提子。
4. 以舒适的节奏清晰点击录制.
5. 记录一段简短的段落,并在继续之前加以审查。

对于复杂的音乐来说,步调时间的输入可能比现场录制需要较少的校正.

### 16. 我该怎么输入和弦而不是单独的音符?

音符在继位时间输入中一次又一次地演奏,通常占据连续的节奏位置.

**解决方案**

对于MIDI输入,在选择所需持续时间后,将和弦的音符一起播放.

用于计算机键盘输入 :

1. 输入第一个音符。
2. 选择它。
3. 使用间隔命令在上方或下方添加注释.

请检查access-date=中的日期值 (帮助) 结果的音符共用一个干线和持续时间.

### 17. 没有数字键盘, 我怎么输入笔记 ?

你可以用西贝利乌斯的屏幕 **键盘 (Keypad)** 即使你的笔记本电脑没有单独的号码

**解决方案**

1. 显示 **键盘 (Keypad)** 从面板控制。
2. 单击所需的持续时间或表达式。
3. 用计算机键盘或MIDI键盘输入投球.
4. 审查可用的键盘快捷集 **首选项 (Preferences)**.

如果您经常输入标记, 您也可以自定义快捷键或连接 USB 数字键盘 。

### 18. 为什么新笔记要替换已有的音乐 ?

注意输入在选定的节奏位置编辑音乐;它不会为每个新想法自动创建额外的栏.

**解决方案**

1. 撤消不想要的编辑 。
2. 在进入新通道前添加所需的栏.
3. 在新栏中选择第一个剩余部分。
4. 开始注意输入

如果你想在同一工作人员身上增加一个独立的节奏,请使用另一个声音而不是取代现有的声音.

## 标记、声音和韵律 {#notation-voices-and-rhythm}

### 19. 我该如何添加还是删除全部栏?

删除注释和删除栏是不同的操作.

**解决方案**

要添加栏,请使用 **家 → 栏 → 添加 (Home → Bars → Add)** 并选择适当的选择。

删除栏:

1. 做一个 **系统选择** 横跨所有栏杆的栏杆
2. 请检查所选区域是否包含您想要删除的条 。
3. 删除选择。

一个正常的通道选择可以在将栏杆留在原位的同时清除音乐内容.

### 20. 我该如何改变拍号而不意外地移动笔记?

变化计数器可以使西贝柳斯将现有的音乐重组为新的栏目.

**解决方案**

1. 省分一卷. 师曰.
2. 选择更改的起始点。
3. 打开 **时间 签名 (Time Signature)** 控制器 控制器
4. 审查重写现有条的选项 。
5. 应用更改并检查受影响的通道。

失效重写保留了现有的条形结构,但它可能留下长度与显示的表不匹配的条形. 故意使用这个选项。

### 21. 我该如何创建皮卡还是阿纳克鲁西斯?

皮卡是一条缩短的开口条,比如在第一整条前拍到一条 4/4.

**解决方案**

创建开张拍号时,请使用 **皮卡/上击** 选项并指定其持续时间。

对于已有的分数,请创建 **不规则栏** ,然后小心地传输打开的音乐。

检查栏码和最终栏,如果棋子需要辅以缩短的结尾.

### 22. 我该如何把两个独立韵律 放在一个工作人员身上?

使用单独的声音进行同步的音乐台词.

**解决方案**

1. 输入第一行 **语音 1**.
2. 选择第二行的起始位置。
3. 选择 **语音 2** 自动调试 **键盘 (Keypad)**.
4. 输入它的音符,独立休息。

声音1和2通常提供对立的干线方向. 仅在标记需要时使用额外声音.

当音符需要不同的节奏时,不要使用和弦.

### 23. 为什么额外休息出现在我的分数里?

每个活跃的声音都需要自己的节奏结构,所以额外的声音可以引入额外的休息.

**解决方案**

1. 选择一个意外的休息并识别其声音。
2. 检查该声音是否包含 需要的笔记在酒吧的其他地方。
3. 酌情删除意外创建的声音 。
4. 只有在音乐上有效时才能隐藏休息。

避免躲藏 只是为了掩盖不完全的节奏 首先,确保每个声音都反映预定的酒吧持续时间。

### 24. 我该如何创建三胞胎和其他小块?

图普列斯将节奏跨度与其正常的组别不同.

**解决方案**

1. 选择一个带有预定基期的注解或休息。
2. 使用 **说明 输入 → 小块 (Note Input → Tuplets)**.
3. 选择需要的拖曳或输入自定义比例 。
4. 输入剩余音符。

对于普通的第八注三进制,以第八注的值开头. 如果拖拉槽占用了错误的跨度,请将其取消并检查起始时间和比例.

### 25. 为什么我的笔记被错误地吸引了?

束子组取决于仪表,其分组设置和任何手动束的变化.

**解决方案**

1. 请检查date=中的日期值 (帮助) Time sign's beat group.
2. 选择受影响的笔记。
3. 使用该 **键盘 (Keypad)** 光束控件,以启动、继续或按需要断梁。
4. 对于一个反复出现的问题,调整分组设置,而不是手动纠正每根梁.

举例来说, 6/8 通常将第八音符分为两组三,而其他仪表则可能需要不同的图案.

### 26. 我该怎么用双层钢管记录?

跨工作人员标记对于手间共用的钢琴段落是有用的.

**解决方案**

1. 输入其原工作人员的通道。
2. 选择应该出现在其他工作人员身上的注释。
3. 使用该 **跨工作人员说明 (Cross-staff Notes)** 命令将其显示移动到上方或下方。
4. 检讨、梁架和工作人员的间隔。

跨工作人员运动保持了笔记与原声的关系. 普通的剪切和粘贴将音乐移动到另一个工作人员身上,可能不会产生相同的标记.

### 27. 为什么我的铁丝网行为像一丝不苟?

捆绑和流鼻涕具有不同的音乐意义.

**解决方案**

使用一个 **领带** 将同一音标的连续音符合并为一个持续时间。 **键盘 (Keypad)** 领带控制。

使用一个 **泥浆** 以表示一个短语或横跨注释的表达方式。 **细 (Slur)** 命令。

如果一个领带没有正确连接,请检查以下音符的发音,意外,语音和节奏位置.

### 28. 为什么意外事件是失踪的还是重新出现的?

Sibelius确定从密钥签名中意外显示,在栏和标记设置中较早的注释.

**解决方案**

1. 检查密钥签名 。
2. 请检查access-date=中的日期值 (帮助) 。
3. 选择注释,并使用 **键盘 (Keypad)**.
4. 在可读性提高时,增加一个提醒性意外。

不要改变实际的投注,只是为了强迫一个符号出现. 意外的展示和音乐的投注都必须正确.

### 29. 我该如何改变音符的谐音拼写?

当平面拼音更适合和谐时,一个音位可能作为尖音输入.

**解决方案**

1. 选择注释或段落。
2. 使用该 **恢复( R) (Respell)** 命令。
3. 请检查date=中的日期值 (帮助) 与和弦和键对齐拼音.

例如,一个音标为F-sharp的音符可能需要在某个特定的谐音语境中写成G-flow.

反弹保留了声波。 转换更改投注并解决一个不同的问题.

### 30. 为什么笔记红在西贝利乌斯?

红色注头通常表示一个投球位于为乐器定义的范围之外.

**解决方案**

1. 检查分配给员工的仪器.
2. 检视文字和音响的投注.
3. 请检查date=中的日期值 (帮助) 仪器范围显示设置 。
4. 决定通道是否适合预定玩家.

范围警告并不自动表示标记错误。 然而,隐藏颜色并不能使不切实际的音符可以播放.

## 分数布局和间距 {#score-layout-and-spacing}

### 31. 在一个系统上我怎样适应更多或更少的条?

西贝利乌斯通常会自动计算系统长度,但可以控制重要的断层.

**解决方案**

1. 选择共享一个系统的条。
2. 使用 **版式 → 格式 → Make into System (Layout → Format → Make Into System)**.
3. 查看拥挤的音符和文字的结果.

或者选择一条条线并添加一条 **系统断开 (System Break)**.

如果许多系统拥挤,则审查工作人员的大小、页边距和音符间隔,而不是强迫每行增加栏杆。

### 32. 为什么西贝利乌斯不回我的得分?

现有的格式化锁和中断可以防止自动布局的改变.

**解决方案**

1. 显示布局标记 。
2. 查找系统断层、页面断层和锁定系统。
3. 选择受影响的通道。
4. 使用 **解锁格式 (Unlock Format)** 在适当情况下。
5. 重新应用你需要的休息。

如果分数已经精心准备了页面转折或出版版式,则首先保存一份副本。

### 33. 为什么史塔夫之间有巨大的差距?

人工移动、避免碰撞或纵向论证可能造成较大差距。

**解决方案**

1. 选择受影响的系统。
2. 使用 **优化工作人员间距 (Optimize Staff Spacing)**.
3. 寻找占据空白的歌词,动态,行或文本.
4. 如果横跨整个页面, 请检查垂直设置 。

如果更早的人工更改是原因,在再次优化之前,请使用适当的员工间距重置命令.

### 34. 为什么Dynamics, Lyrics 或 Text Collide 呢?

自动避免碰撞可以被禁用,俯冲或无法解决拥挤的布局.

**解决方案**

1. 检查一下 **磁性布局 (Magnetic Layout)** 为受影响的对象启用。
2. 重置不必要的人工定位.
3. 优化工作人员间隔。
4. 如果需要,给予系统更多的水平空间.
5. 仅在检查自动布局后进行小的手工调整.

包含过多音乐的系统无论碰撞设置如何,可能需要减少栏杆.

### 35. 我该如何恢复不均匀的横向音符间距?

拖动音符或反复改变间隔,可能会留下一个看起来不一致的通道.

**解决方案**

1. 选择受影响的通道。
2. 选择 **外观 → 重置笔记 → 重设笔记间距 (Appearance → Reset Notes → Reset Note Spacing)**.
3. 检查歌词的间隔,和弦符号和意外.
4. 如果通道仍然拥挤,则调整系统中断。

如果某个物体仍然异常地坐落在远离其音符的地方,请也检查其个别位置.

### 36. 我该怎么隐藏空的刺刀?

隐藏未使用的ta可以使大型综艺节目的分数更容易读取.

**解决方案**

1. 选择有关的系统或通道。
2. 选择 **版式 → 隐藏 Staves 中 → 隐藏空框 (Layout → Hiding Staves → Hide Empty Staves)**.
3. 检查所有必要的仪器是否仍然可见.

载有说明或其他有关物品的工作人员不得视为空置。 在删除任何内容之前检查它 。

使用 **显示空框 (Show Empty Staves)** 当你需要 员工再次出现。

### 37. 我该如何改变乐器的秩序?

更改仪器标签不会移动其工作人员。

**解决方案**

1. 打开 **ưμ㼯A → 文书 → 添加或删除 (Home → Instruments → Add or Remove)**.
2. 在乐谱的乐器列表中选择乐器.
3. 上下移动.
4. 确认变化。
5. 审查括号、保险套和条状物分类。

选择一个适合综艺的顺序,帮助音乐家快速找到自己的角色.

### 38. 为什么乐器名称错误或缺失?

仪器名称可以在第一个系统与后来的系统之间有所区别.

**解决方案**

1. 请检查access-date=中的日期值 (帮助) 乐器的全称和简称.
2. 酌情编辑显示的名称或其乐器设置。
3. 审查乐谱的乐器名称显示设置.
4. 检查一个仪器更改是否引入了另一个标签 。

在读者需要识别时使用全名,并在后续系统上使用明确的缩写.

### 39. 为什么会有不料的空白页?

空白页可能来自一个特殊的分页,标题页设置或导入的格式.

**解决方案**

1. 显示布局标记 。
2. 请检查access-date=中的日期值 (帮助) 前页结尾.
3. 检查一个 **特殊分页 (Special Page Break)** 插入空白页。
4. 删除或调整责任间歇。
5. 在布局变化后回顾以下页面.

不删除音乐以删除格式化创建的页面 。

### 40. 为什么栏码启动或重新启动不正确?

皮卡,移动边界或意外的条码变化会影响编号.

**解决方案**

1. 检查编号不正确之处。
2. 检查一个 **栏数变化 (Bar Number Change)**.
3. 更正或删除更改。
4. 审查条码显示设置 。
5. 检查分数和部分的编号。

决定开箱货是无编号的还是计数的,然后一致适用该公约。

## 部件、打印和导出 {#parts-printing-and-exporting}

### 41. 我该如何创建单个乐器部件?

**动态部件 (Dynamic Parts)** 允许乐谱及其工具部分分享音乐内容.

**解决方案**

1. 打开 **部件 (Parts)** 控制器 控制器
2. 检查哪些部件已经存在 。
3. 打开需要的部分 。
4. 在所支持的地方,创建新部分并选择它应该包含的栏杆.
5. 为玩家调整其布局 。

将音乐编辑保留在链接的分数和部分工作流程中,而不是不必要地保持单独的文件.

### 42. 为什么我的乐器部分有与分数不同的布局 ?

部件有独立的布局要求,包括翻页、工作人员规模和系统间歇。

**解决方案**

1. 打开受影响的部分 。
2. 检查它 **文档设置 (Document Setup)**.
3. 审查自动休息和人工休息。
4. 直接调整该部分的布局 。

通常预计布局会有所不同. 如果音符或节奏出现错误,请检查您是否正在查看正确的链接部分,并且其内容没有隐藏。

### 43. 为什么Multires 在我的部件中缺少或分割 ?

多簧管可以被需要保持可见的音乐指令或物品分割.

**解决方案**

1. 确认该部分启用了多重力 。
2. 检查多层断裂处的栏杆.
3. 检查排练标记、文本、条线、密钥更改和拍号。
4. 仅在确认意外对象为不必要的时才删除。

一些休息是正确的,因为玩家需要看到指令在那个时候.

### 44. 我该如何创建更好的页面 打开部分 ?

玩家需要足够的时间翻开一页而不错过他们的下一个条目.

**解决方案**

1. 打开单个部分。
2. 找到适合翻页的休息位置 。
3. 在实际位置插入分页符。
4. 如有自动翻页选项,请审查。
5. 请检查access-date=中的日期值 (帮助) 最后的页数和系统间隔.

避免制造极其繁忙的页面,只是为了强迫转弯. 从玩家的角度测试布局.

### 45. 为什么我的PDF有错误的大小或边距?

分数的页面设置和打印或导出设置可能不同意.

**解决方案**

1. 请检查页面大小和方向 **文档设置 (Document Setup)**.
2. 请检查archive-date=中的日期值 (帮助) 边际与员工规模.
3. 确认您正在输出预定的分数或部分 。
4. 可用时使用内置的 PDF 导出 。
5. 打开PDF并验证其页面尺寸.

在打印时,请检查纸张大小并分别进行缩放。“整页”可以改变最后的打印工作人员大小。

### 46. 为什么PDF中的音乐符号或字体错误?

缺少字体,替换或字体相关的导出问题,可以改变标记的外观.

**解决方案**

1. 将PDF与屏幕上的分数进行比较.
2. 确认已安装所需的音乐和文字字体 。
3. 尝试西贝利乌斯的内置 PDF 导出 。
4. 在另一个PDF查看器中打开结果.
5. 如果西贝柳斯内部的符号也是错误的,则调查应用程序的字体安装.

如果只有自定义字体失败,请在分数的副本中测试一个标准字体.

### 47. 为什么我不能导出音频文件 ?

音频导出需要一种能够渲染计算机内部声音的回放配置.

**解决方案**

1. 检查选中的播放配置 。
2. 使用支持的虚拟乐器或内部回放声音源.
3. 确认普通的回放作品.
4. 选择 **文件 → 导出 → 音频 (File → Export → Audio)**,如果有的话。

如果回放使用外部硬件合成器,其声音可能需要通过音频接口录制. 将 MIDI 发送到设备不会捕捉到它的音频 。

## 储蓄、回收和业绩 {#saving-recovery-and-performance}

### 48. 撞车后我怎么找回分数?

恢复取决于西贝利乌斯在中断前所保存的东西.

**解决方案**

1. 重新打开Sibelius,检查恢复的快速。
2. 检查可用的自动保存或备份文件 。
3. 使用您版本的保存首选项或参考指南中显示的位置 。
4. 比较时间戳和音乐内容.
5. 以新名称保存最佳恢复版本 。

避免覆盖原件, 直到您确认回收的文件包含您需要的工作 。

### 49. 为什么Sibelius慢, 冻结或崩溃?

原因可能涉及特定的分数,回放库,驱动程序或软件组件.

**解决方案**

1. 省省工作,重启西贝利乌斯.
2. 测试一个小的新分数。
3. 将行为与问题分数进行比较.
4. 测试一个简单的回放配置 。
5. 断开不必要的MIDI和音频设备.
6. 检查兼容的西贝利乌斯和驱动程序更新 。

如果只有一个分数失败,则进行复制并缩小受影响的通道. 如果每个分数都失败,请记录您的版本,操作系统以及支持的准确错误消息.

### 50. 为什么有人能不打开我的西贝利乌斯文件?

收件人可能拥有较旧的版本,限制性版本或文件的不完整副本.

**解决方案**

1. 询问他们使用的西贝利乌斯版本和版本.
2. 支持时,使用 **文件 → 导出 → 上一个版本 (File → Export → Previous Version)**.
3. 发送导出副本并保存原件.
4. 请检查所传输的文件是否完整 。
5. 如果他们使用另一个注解应用程序,则考虑MusicXML.

老版本导出和MusicXML可以改变格式或不支持的特性. 将可编辑文件旁边的 PDF 发送为可视参考 。

## 快速解决问题核对列表 {#quick-troubleshooting-checklist}

在作出重大修改之前:

1. 省别分数本.
2. 确定问题是否影响一个分数或每个分数.
3. 检查选中的音频和MIDI设备 。
4. 检查播放配置 。
5. 查看最近标记或布局变化 。
6. 酌情恢复西贝利乌斯.
7. 检查版本和操作系统兼容性.
8. 一次改变一个设置,测试结果。
