*Από τον John Montgomery*

Τα φώτα αλλάζουν. Κάποιος σας δίνει ένα νεύμα. Η μπάρα ανοίγματος είναι σχεδόν εδώ ⁇ και ξαφνικά το κομμάτι που ξέρατε χθες αισθάνεται λίγο πιο μακριά.

Αν αυτό ακούγεται οικείο, έχετε πολλή παρέα. Η εκτέλεση μπορεί να αισθανθεί συναρπαστική και άβολα ταυτόχρονα.

Αυτό που βοηθάει είναι να έχεις κάτι πρακτικό να κάνεις στη συνέχεια: ένα άνοιγμα που εμπιστεύεσαι, ένα σύνθημα που αναγνωρίζεις και έναν τρόπο να συνεχίσεις αν κάποιο σημείωμα παραστρατήσει.

## Δώστε στον εαυτό σας μια φιλική αρχή

Για έναν πιανίστα, αυτό μπορεί να σημαίνει σιωπηλή εύρεση της θέσης του εναρκτηρίου χεριού και ακρόαση του ρυθμού πριν από την έναρξη. Για έναν τραγουδιστή ή ηθοποιό, αυτό θα μπορούσε να σημαίνει ότι γνωρίζετε την είσοδό σας, την πρώτη ανάσα και την πρώτη πρόθεση στη σκηνή.

Πρόβες που ξεκινούν αρκετές φορές, συμπεριλαμβανομένων των λίγων δευτερολέπτων πριν από αυτό. Καθίστε κάτω, να εγκατασταθούν, να κοιτάξουμε επάνω και να ξεκινήσει. Η εξοικείωση με όλη τη μικρή ακολουθία μπορεί να κάνει το άνοιγμα να αισθάνεται λιγότερο σαν ένα άλμα προς το άγνωστο.

Αυτό είναι προετοιμασία για το υπόλοιπο της παράστασης πάρα πολύ? δεν αντικαθιστά την εκμάθηση ολόκληρο το κομμάτι.

## Κάντε το δωμάτιο μέρος της προετοιμασίας σας

Προσαρμόστε τον πάγκο, οργανώστε στροφές σελίδας, δοκιμάστε τον ήχο και προσδιορίστε από πού θα προέλθουν τα σύνθημά σας.

Μικρές λεπτομέρειες αξίζουν προσοχή. Μπορείτε να δείτε τον μαέστρο; Είναι η μουσική στάση σε άνετο ύψος; Μήπως το εναρκτήριο έμπλαστρό σας έχει τη σωστή ένταση; Μια σύντομη επιταγή μπορεί να αφαιρέσει μια εκπληκτικά αποσπώμενη ερώτηση από το μυαλό σας.

Αν είστε σε μια παραγωγή, ακολουθήστε τις οδηγίες του διευθυντή σκηνής και του μουσικού διευθυντή.

## Αναπνεύστε άνετα και αφήστε τον εαυτό σας να ηρεμήσει

Το NHS συστήνει απαλή, τακτική αναπνοή χωρίς να πιέζει την αναπνοή, εξάσκηση για λίγα λεπτά όταν είναι δυνατόν. Δοκιμάστε ότι κατά τη διάρκεια των συνήθων προπονήσεων έτσι ώστε να γίνει οικεία.

Αφήστε τους ώμους σας να μαλακώσουν, να παρατηρήσετε την υποστήριξη του δαπέδου ή του καθίσματος και να δώσετε στον εαυτό σας χρόνο. Αποφύγετε να αναγκάσει μεγάλες αναπνοές ή μακριά ανάσα κρατά.

Για τους τραγουδιστές και τους παίκτες του ανέμου, κρατήστε τη φυσιολογική τεχνική σας και κάθε προθέρμανση που συμφωνήθηκε με το δάσκαλό σας. Μια ήρεμη ρουτίνα θα πρέπει να υποστηρίξει το παίξιμο σας, αντί να γίνει μια άλλη εργασία για να πάρει το σωστό.

## Βάλε την προσοχή σου στη μουσική.

Ίσως είναι το σχήμα της μελωδίας, ο παλμός του μπάσου, τα λόγια του παρτενέρ της σκηνής σας ή το επόμενο σύνθημα του μαέστρου.

«Ας τραγουδήσει αυτή η φράση» είναι μια πιο χρήσιμη οδηγία στο πληκτρολόγιο από μια συνεχή αναθεώρηση κάθε κίνησης δαχτύλων. Στο μουσικό θέατρο, μια σαφής πρόθεση χαρακτήρα μπορεί να σας δώσει κάτι συγκεκριμένο για να επικοινωνήσετε.

Αυτό είναι εντάξει: ο στόχος είναι να δώσετε την προσοχή σας σε ένα χρήσιμο σπίτι, όχι να απαιτήσετε ένα ιδιαίτερο συναίσθημα.

## Εξάσκηση

Κατά τη διάρκεια της προπόνησης, περιστασιακά παίζουν μέσα από ένα πλήρες τμήμα χωρίς να σταματήσει για να επισκευάσει κάθε ολίσθηση.

Επιλέξτε μερικά ορόσημα ανάκτησης: ένα γράμμα πρόβας, μια σαφής αλλαγή συγχορδίας, την αρχή της επόμενης φράσης. Σε σύνολο παίζει, συνεχίστε να ακούτε και ακολουθήστε τον μαέστρο ή συμφωνημένες ατάκες. Αν χάσετε τη θέση σας, επανέλθετε σε ένα σημείο που μπορείτε να προσδιορίσετε με σιγουριά.

Δοκιμάστε αυτό με ένα φίλο ή μια συσκευή εγγραφής πριν από μια σημαντική απόδοση. Μια σύντομη, χαμηλής πίεσης run-through μπορεί να αποκαλύψει τι χρειάζεται προσοχή, ενώ σας δίνει πρακτική στο φινίρισμα.

## Μια απλή προ-show ρουτίνα

1. **Έλεγξε το στήσιμο σου.** Η μουσική, το όργανο, ο ήχος και οι σκοπευτικές γραμμές είναι έτοιμες.
2. **Ζεστάνετε απαλά.** Χρησιμοποιήστε τη γνωστή ρουτίνα που ταιριάζει στο όργανο ή τη φωνή σας.
3. **Ηρέμησε.** Κράτα το άνετο και αβίαστο.
4. **Θυμηθείτε τα εγκαίνια.** Ακούστε το ρυθμό και μάθετε το πρώτο σας σύνθημα.
5. **Διάλεξε την εστίασή σου.** Μια φράση, ένας στίχος, ένας παρτενέρ σκηνή ή ο μαέστρος.

Στη συνέχεια, γράψτε ένα πράγμα που πήγε καλά και ένα πράγμα να εξασκηθείτε στη συνέχεια. Δώστε στον εαυτό σας πίστωση για την εμφάνιση και τη δημιουργία μουσικής.

## Διατηρήστε την απόλαυσι εν όψει

Υπάρχει χώρος τόσο για την προετοιμασία όσο και για την απόλαυση σε μια παράσταση. Έχετε μια μελωδία για να μοιραστείτε, μια ιστορία για να πείτε ή ένα μέρος για να συνεισφέρετε. Ξεκινήστε εκεί, πάρτε το επόμενο σύνθημα και δώστε στον εαυτό σας την άδεια να απολαύσετε μια καλή στιγμή όταν φτάσει.

Για έναν πρακτικό τρόπο να εξερευνήσετε τις μουσικές επιλογές στο πληκτρολόγιο, ⁇ ίξτε μια ματιά σε μας [Πορεία αυτοσχεδιασμού πιάνου](/el/courses/piano-improvisation/). Προσφέρει έναν τρόπο για να αναπτύξει το παιχνίδι σας? Δεν είναι μια θεραπεία για το άγχος απόδοσης.

Αν το άγχος σας εμποδίζει τακτικά από το να εκτελείτε ή επηρεάζει την καθημερινή ζωή, εξετάστε το ενδεχόμενο να ζητήσετε υποστήριξη από έναν εξειδικευμένο επαγγελματία υγείας.
