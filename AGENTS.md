# Softplanet Productions editorial requirements

## Multilingual content synchronization

Every content change must be reflected in every existing language and regional variant of the affected page in the same change set. This includes titles, meta descriptions, headings, body copy, FAQs, course details, calls to action, offers, and internal links. For new pages, create corresponding localized versions for all configured locales before publication. Discover the current locale list from the Hugo language configuration rather than assuming a fixed list.

- Translate meaning naturally and adapt SEO terminology to local search intent; do not reuse English-market search-volume estimates as local data.
- Preserve stable URLs, translation associations, canonical/hreflang behavior, and valid instructor referral links. Clearly state that the Udemy course is taught in English on translated course pages.
- Keep numerical facts, pricing and offers consistent; verify time-sensitive claims before changing them.
- For shared template text, update the relevant i18n strings in all locales rather than hardcoding English.
- Before release, build the multilingual site and check all affected translated pages, metadata, navigation, and links. Report any missing translations or unverified deployment; do not claim completion when a locale is outstanding.
